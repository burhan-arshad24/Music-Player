# Music Clone

A simple music streaming website clone built using vanilla web technologies.

## Technologies

- HTML5
- CSS3
- JavaScript

## Features

- Music player interface
- Play and pause controls
- Song selection
- Progress bar
- Volume control
- Responsive layout

## Project Purpose

Created as a frontend development project to practice
HTML, CSS, and JavaScript.
